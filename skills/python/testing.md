# Python testing (pytest)
Tags → skill://python/sources.md.

- Layout: `tests/test_<module>.py` beside `src/`, never inside the package; group per unit in `class Test<Unit>:`. [pytest, PyPA, U]
- Names: `test_<unit>_<expected_behavior>`; typed signatures (`tmp_path: Path`, `-> None`). [U]
- Config, pytest ≥ 9: `[tool.pytest]` with `strict = true`, `testpaths = ["tests"]`, `addopts = ["--import-mode=importlib"]`, `filterwarnings = ["error"]`. [pytest]
- Config, pytest 8: `[tool.pytest.ini_options]` with `addopts = "--strict-markers --strict-config --import-mode=importlib"`, `xfail_strict = true`, `testpaths`, `filterwarnings`. [pytest, OAI]
- Run: `uv run pytest`; one test: `uv run pytest tests/test_x.py::TestUnit::test_name`. [uv, pytest]
- Assert caller-visible behavior at the highest boundary; never internal call shapes or expected values recomputed from the implementation. [OAI]
- Plain `assert`; errors via `with pytest.raises(Err, match="…"):`; floats via `pytest.approx(x, rel=…)`. [pytest]
- Structured results: compare whole models (`assert result == Order(order_id=1, total=Decimal("9.50"))`); JSON/dict outputs (HTTP bodies, MCP `structuredContent`, files) validate through the contract first (`Order.model_validate_json(body)`), never key-by-key dict asserts. [U, PYD]
- Every `Field` constraint and validator: one accepting and one rejecting case; rejection via `with pytest.raises(ValidationError, match="<field>"):`. [U, PYD]
- Test data: models via constructors; raw inputs as literals passed to `model_validate`/`model_validate_json`; never `model_construct()` (bypasses the rules under test). [U, PYD]
- Models with aliases or custom serializers: round-trip `Model.model_validate_json(m.model_dump_json()) == m`. [PYD]
- Frame outputs: validate sampled rows (`row.asDict()`, `to_dict("records")`) through a row model. [U]
- Fixtures: function scope by default; widen only for safe shared state; teardown after `yield`. [pytest]
- Files: `tmp_path`; env, attributes, cwd: `monkeypatch`; never the real home, cwd, or global env. [pytest]
- Patch the name where the code under test looks it up. [pytest]
- No network, live credentials, or wall clock: stub transports, inject clocks. [pytest, OAI]
- `@pytest.mark.parametrize(..., ids=[...])`; never mutate parameter objects. [pytest]
- Independent of test order and shared state. [pytest]
- Warnings fail; allow known ones narrowly in `filterwarnings`. [pytest, P565]
- Async tests: `pytest-asyncio` with `asyncio_mode = "auto"`. [OAI]
- Fixture secrets obviously fake (`"test-token"`). [OAI]
